# BPMP_2016

This repository is an alias for **[pachterlab/kallisto_paper_analysis](https://github.com/pachterlab/kallisto_paper_analysis)**, which contains the code and analysis for:

Nicolas L. Bray, Harold Pimentel, Páll Melsted, and Lior Pachter. **[Near-optimal probabilistic RNA-seq quantification](https://doi.org/10.1038/nbt.3519)**. *Nature Biotechnology* 34, 525–527 (2016).

**[Go to the code and documentation →](https://github.com/pachterlab/kallisto_paper_analysis)**

The alias follows the Pachter Lab convention of author last-name initials in order followed by the publication year. The original kallisto_paper_analysis repository remains the source of the code and retains its existing URL.
